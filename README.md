# Headache Assessment & Management

Static web application saved from the existing Vercel deployment.

Live application: https://headache-assessment-management.vercel.app/

## Run locally

Open `index.html` in a browser, or serve this directory using any static web server.

## Deploy to Vercel

Import this repository, select Other as the framework preset, leave the build command empty, and serve the repository root.

## Source

`index.html` preserves the application served by the existing deployment on 29 October 2026. No application logic was intentionally changed.
